# bcGoogleAuth

Example for using AuthenticateGoogleOpenId method in node.js app

After running `npm install`, set up your app:

```
npx @braincloud/client setup
```

Log in, pick your team and app, and it writes `braincloud.config.js` to this folder.
In VS Code, open this folder and run Terminal → Run Task… → **brainCloud: Setup** instead (**brainCloud: Refresh config** re-fetches the config from your saved login without the browser).
