
# FileUploader

Example for adding UserFiles to your app. Recommended as a quick testing tool.

## Setup
From the `client/` folder run `npx @braincloud/client setup` (or open `client/` in VS Code and run the **brainCloud: Setup** task). Needs [Node.js](https://nodejs.org) 18+.

Log in, pick your team and app, and it writes `client/braincloud.config.js` (gitignored). Then open `braincloud-fileuploadtest.html`.
